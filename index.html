    Conceptos clave

    Framework CSS
    Conjunto predefinido de estilos y herramientas que facilitan el diseño y desarrollo de sitios web. Permite ahorrar tiempo al reutilizar componentes y seguir estándares establecidos para lograr un diseño consistente y profesional.
    Bootstrap
    Uno de los frameworks CSS más populares: ofrece componentes predefinidos y un sistema de diseño responsivo basado en cuadrículas. Ideal para páginas que se adaptan automáticamente a diferentes tamaños de pantalla.
    CDN (Content Delivery Network)
    Red de servidores distribuidos geográficamente que permite cargar hojas de estilo o scripts de forma rápida y eficiente. Bootstrap puede cargarse desde una CDN, eliminando la necesidad de descargar archivos localmente.
    Sistema de cuadrículas (Grid System)
    Base del diseño responsivo en Bootstrap: divide la página en filas y columnas (12), facilitando organizar el contenido de manera estructurada y adaptable a diferentes dispositivos.
    Componentes de Bootstrap
    Elementos predefinidos (botones, barras de navegación, carruseles, formularios, modales, cards) que se personalizan y reutilizan para acelerar el desarrollo.
    Clases CSS de Bootstrap
    Sistema de clases CSS prediseñadas que se aplican directamente al HTML para dar estilo a los elementos (p. ej. .btn-primary, .text-center).
    Responsive design
    Capacidad de un sitio web de adaptarse automáticamente a cualquier tamaño de pantalla. Bootstrap lo implementa de forma nativa.
    Flexbox
    Módulo de diseño CSS que Bootstrap utiliza para organizar elementos de manera flexible dentro de contenedores, alineando y distribuyendo el espacio de forma eficiente.
    Breakpoints
    Puntos de corte predefinidos que ajustan el diseño según el tamaño de pantalla (sm, md, lg, xl, xxl).
    Navbar
    Barra de navegación para crear menús interactivos que se adaptan a diferentes dispositivos, incluyendo funcionalidad de colapsar en móviles.
    Carrusel (carousel)
    Componente visual que permite mostrar múltiples elementos (imágenes o texto) de manera dinámica mediante deslizamientos automáticos o manuales.
    Cards (tarjetas)
    Contenedor flexible que permite agrupar contenido como imágenes, texto y enlaces en un diseño limpio y profesional.

    Document Object Model (DOM)
    Representación estructurada de una página web en forma de árbol; permite acceder y manipular los elementos HTML y sus atributos mediante JavaScript.
    Manipulación del DOM
    Modificar, agregar o eliminar elementos del DOM con JavaScript: cambiar textos, estilos o crear estructuras HTML completas de manera dinámica.
    Eventos en JavaScript
    Acciones que ocurren en la página (clics, desplazamientos, envío de formularios) y que permiten asociar funciones que respondan a ellas.
    Fetch API
    Herramienta moderna de JavaScript para realizar solicitudes HTTP y obtener datos externos de servidores o APIs.
    addEventListener
    Método para asociar eventos a elementos del DOM; es flexible y soporta múltiples eventos y funciones.
    Promesas en JavaScript
    Forma de manejar operaciones asincrónicas mediante .then() y .catch().
    Eventos de formulario
    Interacciones relacionadas con formularios, como el envío de datos (submit), que permiten validar o procesar información.
    Eventos de mouse
    Interacciones del puntero: click, mouseover y mouseout.

    Modales (modals)
    Ventanas emergentes ideales para mostrar información o capturar datos rápidamente mediante formularios personalizados, como en registros o confirmaciones.
    Tarjetas (cards)
    Contenedores visuales versátiles que organizan y presentan contenido como productos, noticias o secciones destacadas de forma compacta y atractiva.
